# Control of Palaeogeography on sea ice in the Cenozoic

<p>
These models are ran with 190 pCO2, same as LGM, to promote sea ice formation to identify how changing palaeogeographies control sea ice formation. Models are muffingen re-grids of the Farnsworth et al. (2019), using stage-wise timesteps with the age of each model being placed around the mid-point of each stage.
</p>
